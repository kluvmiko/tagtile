# TagTile v1

A mobile-first TagTile MVP that supports:
- A unique, permanent QR URL for each tile
- First scan opens the customization form
- Saving creates the profile
- Later scans open the public profile immediately
- Private edit link for changing a profile later
- Name, bio, profile-photo URL, six color themes, and four custom links

## Important: this project is not connected to your live Netlify site yet

The original `tagtile.html` was a static landing page with a placeholder button. This project replaces it with the first working app. Deploy these files to the same Netlify site only after the Supabase setup below is complete.

## 1. Create the database

1. Create a project at https://supabase.com/.
2. Open **SQL Editor**.
3. Paste and run `supabase-schema.sql`.
4. In **Project Settings → API**, copy the Project URL and the `service_role` key. Keep the service-role key private.

## 2. Add Netlify environment variables

In Netlify, open your TagTile site → **Site configuration → Environment variables** and add:

- `SUPABASE_URL` = your Supabase Project URL
- `SUPABASE_SERVICE_ROLE_KEY` = your Supabase `service_role` key

Never put the service-role key in `index.html`, public JavaScript, or a QR code.

## 3. Deploy

Upload the contents of this folder to your site's deploy source, or connect this folder through a Git repository. Netlify should detect `netlify.toml` and deploy the function in `netlify/functions/profile.mjs`.

## 4. Test the flow

1. Open the homepage and press **Create your TagTile**.
2. A unique QR code and URL are generated.
3. Open that URL on a phone or scan its QR code.
4. Complete the customization form and save.
5. The app displays a private edit link. Save it somewhere safe.
6. Scan the same QR code again. It should open the public profile, not the setup form.
7. Open the private edit link to change the profile. Changes appear on the same public QR URL.

## Notes before selling physical keychains

- This is an MVP. It does not yet include customer accounts, an admin inventory dashboard, payments, file uploads, analytics, or lost-edit-link recovery.
- A generated QR is permanent as long as the TagTile site/domain remains active.
- The QR image is generated by QRServer when the user creates a tile. You can replace this with a self-hosted QR library later.
- The private edit URL is a bearer secret: anyone who has it can edit that profile. Do not post it publicly. If it is lost, there is no recovery flow yet.
- Profile photos currently use an image URL. Add private upload storage before promising hosted photo uploads.
- Add rate limiting, abuse prevention, and a privacy policy before public commercial launch.
